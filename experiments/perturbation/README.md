# Feature transformations and perturbations

`run.py` generates layer perturbations using the original-coordinate CAE; `analyze.py` evaluates those fields. `transformations.py` evaluates time reversal, coordinate permutations, and rotations. Recorded small metrics are in `results/`.

See [RUNNING.md](../../docs/RUNNING.md) for commands. Write new artifacts under
`outputs/perturbation/`; `results/` directories contain recorded reference metrics.
