# Classical-system fusion

`run.py` handles CAE training and content/content-style generation. `evaluate.py` reconstructs fields and evaluates dynamics. `plot.py` renders recorded or regenerated metrics. `reconstruct.py` evaluates CAE reconstruction. Presets, optimizer settings, and evaluation metadata are in `configs/`.

See [RUNNING.md](../../docs/RUNNING.md) for commands. Write new artifacts under
`outputs/classic/`; `results/` directories contain recorded reference metrics.
